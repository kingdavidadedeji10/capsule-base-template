# capsule-base-template
Production-ready Next.js 15 + Supabase + Tailwind + shadcn/ui base template for Capsule AI.

## Setup
1. `npm install`
2. `cp .env.local.example .env.local` — fill in Supabase keys
3. `npm run dev`

## Branches
- `main` — clean base
- `fintech-template` — fintech app with Paystack
- `ecommerce-template` — ecommerce app (coming soon)
